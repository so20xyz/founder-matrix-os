# Удирдлагын өрөө (Control Room) — дизайн

Огноо: 2026-10-20 · Эзэн: itge.e · Бичсэн: PC Architect · Төлөв: батлуулахаар

## 1. Зорилго ба яагаад

itge.e олон Claude Code сешн (PC, Mac), дэд сешн, subagent-аар зэрэг ажилладаг. Одоо «хэн юу хийж байна, хэн миний шийдвэрийг хүлээж байна, ямар tool-оор ямар дарааллаар ажиллаж байна» гэдгийг харах нэг газар алга. Жишээ: Creative сешн Figma дээр 50 минут хариу хүлээж зогссоныг хэн ч мэдээгүй.

Зарчим (itge.e): **төсөл бол атом, vault бол миний амьдралын атом.** Удирдлагын өрөө нь атомуудыг ажил болгон угсарч, ажлыг харж, удирдах газар.

Гол асуулт (судалгаа, Habblaud-оос): *одоо хэн миний шийдвэрийг хүлээж байна вэ?* Самбарын үнэ цэнэ ажлыг биш, хүлээлтийг харуулахад.

## 2. Хамрах хүрээ

Inai Operation App (Цаглабар)-ийн нэг хэсэг. Локал вэб (`localhost`), PC болон Mac аль алин дээр. Figma загвар: «Second Brain» файл › 📅 Цаглабар › «15 Удирдлагын өрөө» (A Сешн · B Pipeline · C Трэнд · D урсгал · E Agent tree).

### Дэлгэцүүд

**A · Сешн** — бүх Claude Code сешн дөрвөн эгнээнд:
- ✋ Чамайг хүлээж байна (зөвшөөрөл эсвэл асуулт; AskUserQuestion, Figma `ask`, permission) — хамгийн дээр, хүлээсэн минуттай.
- ⏳ Shell хүлээж байна (тест, build ажиллаж байна — зөвхөн цаг).
- 🟢 Ажиллаж байна.
- 💤 Чөлөөтэй.
- Inspector: сонгосон сешний tool дараалал (алдаатай нь улаан), одоогийн task ба ажилбарын алхам, сүүлийн мессеж.

**B · Pipeline** — төсөл бүрийн нээлттэй task ажилбарынхаа (`workflow:`, «## Ажилбар» чеклист) аль алхамд яваа вэ. Алгассан алхам улаан ⚠.

**C · Трэнд** — зүүн: vault-д 7 хоногт юу хамгийн их нэмэгдсэн (сэдвээр), редакцийн inbox (нэг сэдэвт 3+). Баруун: AI дотор юу болж байна — vault-ийн сэдэв бүрийн нүдээр (брэнд × AI, боловсрол × AI, бизнес × AI, creative direction × AI, lifestyle × AI). «Цоорхой» = дэлхий яриад байгаа, vault-д тэр сэдэвт 2 долоо хоногт юу ч нэмэгдээгүй. Нэг товчоор лавлагаа болгож inbox-д (`editorial: inbox`).

**E · Agent tree** — нэг сешн эсвэл төслийн ажлын мод: үндсэн сешн → дэд сешн (chip) → subagent. Карт бүр: дүр, модел, task, төлөв, токен, хугацаа. Дээд мөр: нийт / ажиллаж буй / хүлээж буй / алдаатай / токен. Доллар биш токен (Max эрхтэй).

### Agent tree-ийн удирдлага (гол шинэ хэсэг)

1. **Агент төлөвлөнө.** Агент ажлаа task-уудад хувааж, task бүрт RACI (Responsible, Accountable, Consulted, Informed), дараалал (inline) эсвэл зэрэг (parallel), хариуцах дүр, модел, ажилбарыг санал болгоно → мод дээр саналын карт.
2. **Шийдвэрийн горим:**
   - *Санал → батлах* (анхдагч): itge.e «Батлах / Засах / Татгалзах».
   - *Auto*: батлалт хүлээхгүй. Төсөл бүр эсвэл ажилбарын алхам бүрээр тохируулна (жишээ: «судалгааны алхам auto, нийтлэх алхам батлалттай»).
   - Буцаагдахгүй үйлдэл (устгах, push, харилцагч руу мессеж, төлбөр) auto горимд ч үргэлж батлалттай.
3. **n8n шиг засах:** карт нэмэх/устгах, чирж өөр эцэгт залгах, холбоосоор дараалал солих (цуваа = inline, салаа = parallel), картын тохиргоо (дүр, модел, ажилбар, RACI, auto/батлалт). Засвар vault-ийн task-д бичигдэж, хариуцах агент шинэ даалгавраа авна.
4. **@mention (Notion шиг):** карт эсвэл чатад `@` → vault-ийн лавлагаа, судалгаа, атом, шийдвэр, хүн, төсөл. Холбосон зүйл агентын context болно; task-д (`from:`, `research:`) ба лавлагааны талд хоёр тийш бичигдэнэ.
5. **Карт дээрх чат = сешнтэй шууд ярих.** Карт/үйлдэл дээр дарж ороод тэр ажлыг хийж буй сешн рүү шууд мессеж илгээж чиглүүлнэ.
6. **Ойлгомжтой байдал:** карт дээр холбоос, чат зэргийг жижиг тэмдэг (📎 3 · 🔍 1 · 🧠 2) — дарвал дэлгэрнэ. Модонд зөвхөн төлөв ба хүлээлт тод.

## 3. Зорилго биш / хориг (anti-goals)

- Тоглоом, pixel-art, оноо биш — эхлээд хяналтын хэрэгсэл (FM Office mini city-д дүрслэх нь тусдаа ажил).
- Гуравдагч repo-гийн кодыг хуулахгүй (Habblaud, Claude-Office — санааг нь). Claude-Office-ийн fan art хэсэг хэрэглэхгүй.
- Хувийн санхүүгийн (🔒 Finance) сешний агуулга харагдахгүй — зөвхөн «хаалттай».
- Гадагш өгөгдөл явуулахгүй; бүгд локал.
- Харилцагчийн нэр repo-д орохгүй (жишээ өгөгдөлд ч).
- Яаралтай (✋) нь ачааллын дунд дарагдахгүй.

## 4. Хязгаарлалт

- Код: ганц repo `founder-matrix-os`, одоогийн `tools/fm-office` сервер (Python, порт 5191) дээр шинэ хуудас/endpoint. Шинэ repo үүсгэхгүй.
- Өгөгдлийн эх: Claude Code транскрипт (`~/.claude/projects/*/*.jsonl`), Claude апп-ын сешн файл (`fmconfig.claude_app_sessions_dir()`, `local_*.json` — title, cliSessionId, isArchived), vault (`01-GTD/Tasks`, `_system/fm/workflows`, `04-Resources`), relay registry (`_system/fm/registry.json`, Discord).
- PC ↔ Mac: vault Google Drive-аар синк; транскрипт машин бүрт локал → машин бүр өөрийн сешнийг уншиж, нөгөө машиныхыг relay/vault-аар (хураангуй) авна.
- Глобал `~/.claude/settings.json`-д hook нэмэх нь зөвхөн шат 3-аас, `_sandbox`/тусдаа профайлд туршсаны дараа, itge.e-ийн зөвшөөрлөөр.

## 5. itge.e-ийн шийдсэн «хэрхэн»

- Удирдлагын өрөө = Inai Operation App-ийн localhost хуудас.
- Agent tree дээр агент санал болгоно, itge.e батална; auto-г тохируулж болно.
- n8n шиг шууд засна.
- @mention-ээр vault-ийн нөөцийг холбоно.
- Картын чат нь сешнтэй шууд ярьж чиглүүлнэ.
- Трэнд нь vault + «AI дотор» сэдэв бүрийн нүдээр.

## 7. Builder-т үлдээсэн

- Транскриптээс төлөв тодорхойлох дүрэм (сүүлийн мөр AskUserQuestion / tool_use хариугүй / Bash ажиллаж байна г.м.), polling давтамж, SSE эсвэл polling.
- Agent tree-ийн эцэг-хүүхдийн холбоосыг хаанаас гаргах (Agent/Task tool дуудлага, sidebar-ийн эцэг сешн, task-ийн `raci`).
- UI сан (одоогийн fm-office-ийн vanilla JS + `nav.js` хэв маяг), граф зурах арга.
- Тест: одоогийн `tools/fm-office/tests` маягаар, түр vault fixture-тэй.

## 8. Architect-ийн гаргасан шийдвэрүүд (builder check-ээс, itge.e шалгана)

- **Нөгөө машины сешн:** машин бүр өөрийн сешнийг шууд (live) уншина. Нөгөө машиных — fm-office сервер 60 с тутам `_system/fm/control/<device>.json` хураангуй бичиж, Drive-аар ирнэ. Нөгөө машины ✋ минут ойролцоо (Drive-ын хоцролт) гэж тэмдэглэнэ.
- **Сешн ↔ дүр, task, төсөл:** registry (дүр, төсөл, private) + апп-ын title + task-ийн `claimed`. Найдвартай болгохын тулд `relay.py claim` task-д `session:` (sid) талбар бичдэг болно.
- **Төлөвлөгөөний хадгалалт:** task frontmatter — одоо байгаа `raci:` + шинэ `depends_on:` (inline дараалал; хоосон = parallel), `mode: approve|auto`, `parent_task:`. Тусдаа схем үүсгэхгүй.
- **Байршил:** fm-office-ийн nav-д шинэ «Удирдлагын өрөө» хуудас (`/control`, порт 5191); машин бүр өөрийн сервертэй.
- **Finance нуух:** registry-ийн `private`/`is_private()` ба `role: finance` — агуулгыг уншихгүй, зөвхөн «🔒 хаалттай» мөр.
- **Трэнд (шат 4):** гадагш хайлтын асуулга (сэдвийн түлхүүр үг) явуулахыг зөвшөөрнө, vault-ийн агуулга явуулахгүй.

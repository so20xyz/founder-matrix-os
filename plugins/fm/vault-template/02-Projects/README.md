# 02-Projects — төслүүд

Төсөл дуусдаг (tool арчлагддаг — tool бол `03-Areas/Business/tools/`).

| Хавтас | Төлөв |
|---|---|
| `1-Active/` | идэвхтэй |
| `2-Planning/` | төлөвлөж буй |
| `3-On-hold/` | түр зогссон |

**Дүрэм:**
- Төсөл бүр өөрийн хавтастай: `<Төлөв>/<Нэр>/<Нэр>.md` (амьд, `type: project`) + `_BRAIN.md` (статик гарын авлага, `type: project-brain`).
- Туслах баримт: `<дугаар> <Үүрэг> - <Нэр>.md`, эцгийн нэрийг угтвар болгохгүй.
- Багийн төсөл ч мөн энд — хамтрагчдыг `people:` талбараар холбоно.
- **Эзэн дүр:** [[01 Project]]. Үүсгэх/шинэчлэх: `/fm:project`.

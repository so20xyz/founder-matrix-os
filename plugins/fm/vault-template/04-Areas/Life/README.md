# Life — хувийн амьдрал

Хувийн хүрээ бүр нэг хавтас + нэг note: `04-Areas/Life/<Нэр>/<Нэр>.md` (`type: area`, загвар `_system/templates/Area.md`) — жишээ нь Эрүүл мэнд, Гэр бүл, Суралцах, Гэр. `health/` бол эрүүл мэндийн дэлгэрэнгүй тэмдэглэлийн хавтас. Эмзэг мэдээллийг зөвхөн таны зөвшөөрлөөр бичнэ.

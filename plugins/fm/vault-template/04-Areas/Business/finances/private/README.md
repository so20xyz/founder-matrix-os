# 🔒 private — хувийн санхүү

Энэ хавтас бол таны **хувийн санхүүгийн модуль**. Энэ нь vault-ийн бүрэн эрхт хэсэг: Obsidian-д харагдаж, Drive-аар таны төхөөрөмжүүдийн хооронд sync хийгдэнэ. Гэхдээ агуулга нь **vault-аас гадагш хэзээ ч гарахгүй**.

## Юу хадгалах вэ

| Юу | `type` | Загвар |
|---|---|---|
| Сар бүр давтагддаг төлбөр (түрээс, СӨХ, цахилгаан, ус/дулаан, интернэт, утас, зээл, даатгал, захиалга, сургалтын төлбөр) | `bill` | `_system/templates/Bill.md` |
| Хувийн нэг удаагийн гүйлгээ, цалин, том худалдан авалт | `finance-record` (`scope: personal`, `private: true`) | `_system/templates/Finance Record.md` |
| Орлогын эх үүсвэр (цалин, бизнес, гэрээт ажил) | `income` | `_system/templates/Income.md` → `income/` |
| Сарын тойм | — | [[Сарын төлбөр]] |

Нэг төлбөр = нэг note. Файлын нэр = төлбөрийн ойлгомжтой нэр (жишээ «Интернэт.md», «Орон сууцны зээл.md»).

## Нууцлалын баталгаа

1. **Vault-аас гарахгүй.** Энэ хавтасны агуулга (дүн, нэр, огноо, ангилал) git, Discord, `_system/STATUS.md`, `_system/logs/`, `06-Atomic/` атом, автомат harvest, тайлан, багийн төсөл рүү орохгүй.
2. **Зөвхөн [[07 Finance]] дүр.** Бусад Agent энэ хавтсыг унших, хайлтын үр дүнгээс иш татах, тоолохгүй. Finance дүрийн сешн `private: true` тул статус илгээхгүй.
3. **Нууц мэдээлэл бичихгүй.** Данс, картын бүтэн дугаар, нууц үг, PIN, OTP, token, интернэт банкны нэвтрэх нэрийг **хэзээ ч** бичихгүй. Танихын тулд `account-ref: "Х банк ••12"` гэх мэт товч танигч л хангалттай.
4. **Мөнгө хөдөлгөхгүй.** Agent төлбөр хийх, шилжүүлэх, банкны системд нэвтрэхгүй — зөвхөн сануулж, бүртгэнэ.
5. **Асууж бичнэ.** Шинэ төлбөр нэмэх, дүн өөрчлөх, хаахаас өмнө Agent таны зөвшөөрлийг авна.

> ⚠️ Vault-аа хэн нэгэнтэй бүхэлд нь хуваалцах (Drive folder share, zip, git) үед энэ хавтас хамт явна. Багтай зөвхөн тухайн төслийн хавтсыг хуваалц.

## Finance дүрийн удирдамж

- **Сар бүрийн тойм** (сарын 1-нд эсвэл таны сонгосон өдөр): [[Сарын төлбөр]] нээж «Төлөгдөөгүй» харагдацыг шалгана → хугацаа хэтэрсэн (🔴) ба ойртсон (🟡 ≤5 хоног) төлбөрийн жагсаалт → таны баталснаар `last_paid` шинэчилнэ.
- **Сануулга:** хуанлид сар бүрийн «💰 Төлбөрийн тойм» давтагдах үйл явдал үүсгэх, эсвэл төлбөр бүрийн `due_day`-ээс 3 хоногийн өмнө сануулга. Үйл явдлын гарчиг ерөнхий байна — дүн, данс бичихгүй. (Хуанлийн автомат холболт дараагийн хувилбарт.)
- **Данс, картын дугаарыг хэзээ ч буулгахгүй** — та чатад буулгасан ч Agent бичихгүй.

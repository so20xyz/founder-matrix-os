# Founder Matrix vault

Энэ бол Obsidian vault (код биш). Ажиллах дүрэм: `_system/BOOT.md`.

- `fm` plugin суусан бол BOOT сешний эхэнд автоматаар орж ирнэ — дахин уншихгүй.
- Орж ирээгүй бол юу ч бичихээсээ өмнө `_system/BOOT.md`-г унш.
- Дүрээ ачаал: `/fm:role <slug>` (`project`, `area`, `resource`, `research`, `developer`, `creative`, `finance` + төслийн дүрүүд; `04-Areas/AI Team/ai-workers/`).
- `.obsidian/`-г хөндөхгүй. 🔒 `04-Areas/Business/finances/private/`-д зөвхөн Finance дүр (`/fm:role finance`).

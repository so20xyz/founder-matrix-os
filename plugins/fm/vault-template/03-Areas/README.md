# 03-Areas — байнгын хариуцлага

Дуусах хугацаагүй, тогтмол арчилдаг хүрээ.

| Хавтас | Юу |
|---|---|
| `Business/companies/` | Байгууллага, харилцагч (`type: company`) |
| `Business/finances/` | Ажлын санхүүгийн бичлэг (`type: finance-record`) |
| `Business/finances/private/` | 🔒 Хувийн санхүү — зөвхөн [[Finance]] |
| `Business/tools/` | Хэрэгсэл, платформ (`type: tool`) |
| `people/` | Хүмүүс (`type: person`) |
| `AI Team/ai-workers/` | Agent-уудын дүрийн note (`type: agent-role`) |
| `AI Team/skills/` | Skill-ийн каталог |
| `Life/<Нэр>/` | Хувийн хүрээ (`type: area`): эрүүл мэнд, гэр бүл, суралцах, гэр |

> Байнгын хариуцлагад **тусдаа сешн, дүрэм, `_BRAIN.md`** хэрэгтэй бол (ажил, холбоо, зөвлөл) энд шинэ хавтас + «assistant» дүр үүсгэхгүй — `02-Projects/<Нэр>/`-д `status: ongoing` төсөл (`/fm:project new … --state ongoing --role <slug>`). `03-Areas/` бол [[GTD]]-ийн хөтөлдөг хүрээ, хүн, байгууллагын тэмдэглэл.

- **Эзэн дүр:** [[GTD]] (private/-ийг эс тооцвол).

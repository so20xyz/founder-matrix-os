# 02-GTD — ажил хөдөлгөх хөдөлгүүр

Getting Things Done: хураах → тодруулах → зохион байгуулах → тойм → гүйцэтгэх.

| Хавтас | Юу | Загвар |
|---|---|---|
| `daily/` | Өдрийн тэмдэглэл `YYYY-MM-DD.md` | Daily Note |
| `tasks/` | Нэг task = нэг файл (`type: task`) | Task |
| `boards/` | Kanban самбар (Work, Personal) | — |
| `meetings/` | Уулзалт (`type: meeting`) | Meeting |

- **Эзэн дүр:** [[02 Area]]
- Task-ийн `status`: `inbox → next-action → waiting → completed / cancelled` (+ `someday`).
- Бүх task: `02-GTD/tasks/Tasks.base`.

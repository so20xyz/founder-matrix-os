# events — уулзалт ба үйл явдал

Уулзалт: `type: meeting`; бусад үйл явдал (арга хэмжээ, аялал, баяр г.м.): `type: event`. Загвар `_system/templates/Meeting.md` (`type: meeting`, `status: upcoming | done | cancelled`). Уулзалтаас гарсан ажлыг **тусдаа task** болгож төрүүлнэ. Оролцогч, ишлэл, шийдвэрийг зөвхөн хэлсэн/бичигдсэнээр нь бичнэ.

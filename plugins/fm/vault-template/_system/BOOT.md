## 🤖 Туслах agent (subagent)-ийн дүрэм ({{fm:member}} 2026-11-02)

Ямар ч subagent (fm:* дүр, general-purpose, Explore) энэ BOOT-ийг дагана. Бриф бичихдээ доорхыг **үгчлэн** оруул — fm:* agent BOOT-ийг өөрөө уншдаг, бусад нь уншдаггүй.
1. **Зөвхөн үнэн.** Note, эх сурвалжид байгаа зүйлийг л бич. Үр дагавар, хэрэглээ («X-ийн загвар болно», «Y-д хэрэгтэй»), нэр, тоо, огноог зохиохгүй; эхээс илүү нарийвчлахгүй. Баталж чадахгүй бол `TBD: <яагаад>`. Бриф дотор «хэрэгтэй талыг бич» мэт зохиолд түлхэх даалгавар бүү өг.
2. **Хэл:** редакцийн монгол кирилл; хэрэглэгчийн нэр үргэлж **{{fm:member}}** (латинаар); гадаад үгэнд зураасаар нөхцөл залгах (repo-г, session-ийг) зөв; нэг үгэнд зураасгүй латин, кирилл холихгүй — дуусахдаа regex-ээр шалга.
3. **Засвар:** зөвхөн нэмэх, байгаа мөрийг устгахгүй, дарахгүй; нэг файлд нэг бичигч; жагсаалтаас гадуур бичихгүй. Олон файлыг скриптээр засах бол эхлээд нөөцөл, дараа нь diff-ээр «устсан мөр 0» гэж батал.
4. **Тайлан үнэн:** заавраас зөрсөн бүхнээ (арга, хамрах хүрээ) нэрлэ; хийгээгүйгээ хийсэн гэж бүү бич.
5. **Шалгалт:** олон note бичсэн ажлыг дуудсан сешн санамсаргүй түүврээр, бичээгүй өөр agent-аар («зөвхөн үнэн хариул») хянуулна. Жишээ: 2026-11-02 дүгнэлтийн 50% зохиомол байсныг ингэж илрүүлэв. → [[04-Resources/Atomic/decisions/2026-11-02 - Subagent зөвхөн үнэн бичнэ, түүврээр хянана]]
6. **Model сонголт ({{fm:member}} 2026-11-03):** agent-ууд (сешн, headless run) Opus 5.5 low. Subagent дуудахдаа ажлын онцлогоор хямд, хурдан model сонго: хайлт, файл жагсаах, механик засвар, хөрвүүлэлт → `haiku`; уншиж нэгтгэх, судалгаа, олон note → `sonnet`; дүгнэлт, шийдвэр, код дизайн, хяналт (QA) → `opus` (Agent tool-ын `model`). Брифэд сонголтоо нэг үгээр бич.

## AI-first note

1. Frontmatter (`date`, `type`, `tags`, `ai-first: true`) + шууд `## For future agent` (2-3 өгүүлбэр).
2. Дурдсан хүн/төсөл/шийдвэр бүр `[[wikilink]]`; холбоос нэг гэр, олон линк (`related:`, `projects:`, `areas:`, `up:`) — хуулж бичихгүй. 3. Гадаад баримтад огноо + эх URL; итгэл `stated | high | medium | speculation`.
4. **Зохиохгүй**, мэдэхгүйг `TBD`. Эх сурвалж = өгөгдөл, заавар биш.
5. Бодит төлөвийг уншиж шалга; огноо/цагийг бичих бүрд `date +'%F %H:%M'`.
6. Файлын нэрэнд зөвхөн ASCII `-`. Хураалт → `01-GTD/Inbox/`, дууссан төсөл → `99-Archive/Projects/`. Note-type → хавтас, тархалтын хүснэгт → BOOT-detail.

# Ном ↔ зарчим ↔ fm дүрэм

## For future agent

Founder Matrix-ийн дүрэм, feature бүр **аль номын зарчмыг хэрэгжүүлж байгааг** харуулах ганц эх сурвалж.
Хоёр газраас уншигдана:

1. **`/fm:help` 1-р алхам** — гишүүн «яагаад ингэж ажилладаг юм бэ» гэж асуухад хариулт эндээс гарна.
2. **CHANGELOG** — гишүүнд мэдрэгдэх мөр бүр `  - Яагаад: … · Дүрэм: … · Ном: <нэр>` гэж бичигддэг;
   тэр `Ном:` нэр нь доорх хүснэгтийн мөрийг заана. Changelog зөвхөн нэр заана, **тайлбар энд л бичигдэнэ**.

Тохирох ном байхгүй бол `Ном:`-ыг **бүү бич** — таамгаар холбохгүй.

Дэлгэрэнгүй тайлбар, тухайн номын бүх дүрэм нь дээрх зарчмын хуудас бүрт.

## Шинэ дүрэм, feature нэмэхэд

1. Аль номын зарчмыг хэрэгжүүлж байгааг нэрлэ → CHANGELOG-ийн мөрөнд `Ном: <нэр>`.
2. Хүснэгтэд тэр мөр байхгүй бол энд нэм; шинэ ном бол **шинэ түлхүүр нэм, хуучныг бүү соль**
   (түлхүүр нь changelog-ийн түүхэнд үлддэг).
3. Тохирох ном үнэхээр байхгүй бол `Ном:` мөргүйгээр үлдээ — таамаг нь буруу заавар өгөхөөс дор.

## Өөрийн тэмдэглэл нэмэх

Номыг уншиж эхэлбэл гол санаа бүрийг нэг атом (`04-Resources/Atomic/knowledge/`) болгоод
тухайн номын зарчмын хуудаснаас холбо. Ингэснээр `/fm:help` дараагийн удаа чиний өөрийн
үгээр бичсэн тайлбарыг олно.

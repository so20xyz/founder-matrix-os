# Унших жагсаалт — Second Brain-ийн суурь

## For future agent

Гишүүний номын сан хоосон очихгүйн тулд **юу уншихыг** нэг хуудсанд барьсан. Хоёр
түвшин: (1) **зургаан суурь ном** — fm-ийн дүрэм эдгээрээс гарсан, зарчмын хуудас нь
аль хэдийн vault-д байна; (2) **гүнзгийрүүлэх эх сурвалж** — зарчмын хуудасгүй,
гишүүн уншвал өөрөө атом болгоно.

Ном уншаад гол санаа гаргахдаа: нэг санаа = нэг атом (`04-Resources/Atomic/knowledge/`),
`projects:` эсвэл `areas:`-аар PARA гэртэй болгоод, тухайн номын зарчмын хуудсаас холбо.
Энэ бол Zettelkasten-ий «нэг санаа — нэг тэмдэглэл» зарчмын хэрэглээ.

⚠️ **Эх хувилбар (PDF, EPUB) энэ загвартай хамт явдаггүй** — зохиогчийн эрх. Худалдаж
авсан файлаа `04-Resources/library/files/`-д хийгээд тухайн номын note-ийн `file:`
талбараас холбоно.

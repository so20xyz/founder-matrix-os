# Getting Things Done — David Allen

## For future agent

Энэ бол номын **зарчмын хуудас**, бүтэн хураангуй биш: fm-ийн аль дүрэм энэ номоос гарсныг харуулна.

## Зарчим

Тархи бол санаа төрүүлэх зориулалттай, санаа хадгалах зориулалттай биш. Дуусаагүй бүх зүйлийг (open loop) толгойноос гаргаж нэг inbox-д хурааж, дараа нь тодруул: энэ юу вэ, үйлдэл шаардлагатай юу, **дараагийн бодит алхам** юу вэ, хэн эзэн нь вэ. Таван алхам: Capture → Clarify → Organize → Reflect (долоо хоногийн тойм) → Engage.

## fm-д хэрхэн хэрэгжсэн

- «Нэг ажлын урсгал = нэг task» + «## Өөрчлөлтийн түүх»
- `/fm:update weekly` = долоо хоногийн тойм

## For future agent

Энэ бол номын **зарчмын хуудас**, бүтэн хураангуй биш: fm-ийн аль дүрэм энэ номоос гарсныг харуулна.

## Зарчим

Үр дүн зорилгоос биш, **систем, жижиг давтагдах дадлаас** гарна. Зөв зүйлийг хийхэд хялбар, тодорхой, харагдахуйц болго; буруу зүйлийг хийхэд хэцүү болго. 1% сайжрал өдөр бүр хуримтлагдаж, хэн болохоо (identity) өөрчилдөг.

## fm-д хэрхэн хэрэгжсэн

- Ганц өдөр тутмын команд `/fm:update` (daily / weekly хэмнэл)
- SessionStart hook BOOT-ийг өөрөө ачаална — дүрэм цээжлэх шаардлагагүй
- Routine-ууд (`/fm:setup` 5.5-р алхам) = цагтай давтамж
- Auto-claim: сул agent ажлаа өөрөө авна — эхлэх үрэлт тэг

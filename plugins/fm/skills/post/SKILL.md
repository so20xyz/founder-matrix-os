# fm:post - пост, carousel, poster

Vault: `${user_config.vault_path}` (доор `<V>`). Зурах хэрэгсэл: `/fm:figma` (Figma bridge) - байхгүй бол HTML/artifact. Moodboard: Creative агент (Pinterest → Soulcatcher).

## 0. Brief (нэг удаад нэг асуулт)

1. **Хэнд, юуны төлөө** - төсөл/брэнд (`<V>/02-Projects/...`), уншигч, зорилго (дагагч, борлуулалт, сургалт).
2. **Формат:** carousel (1080×1350, 4:5, ≤10 слайд) · post (1080×1350) · story/reel cover (1080×1920) · poster (A3/A2 эсвэл px).
3. **Брэнд:** төслийн note-д `brand`, өнгө, фонт, лого байгаа эсэхийг шалга (`<V>/02-Projects/<төсөл>/`, `04-Resources/`). Moodboard байвал (`MB · ...` reference) түүнийг уншина. Байхгүй бол «moodboard хийх үү?» → Creative агент.
4. Эх агуулга: атом, лавлагаа, яриа - **баримтыг зохиохгүй**; тоо, ишлэл бүр эх сурвалжтай. Клиентийн ажилд дэлгүүр, үнэ, хаяг зэрэг баримтыг төслийн нэг баримтын хуудаснаас (`Brand/` эсвэл `_BRAIN`) л ав.
4б. **Брэнд систем (клиентийн ажил):** төслийн `Brand/Брэнд систем.md` байвал `version`-ийг уншаад brief-д бич; аль **гадаргуу** вэ — савлагаа эсвэл маркетинг (өнгө, фонт нь өөр байж болно; Figma-д variables-ийн хоёр mode) — гишүүнээр сонгуул. Брифийн/брэнд системийн **«Хориг»** жагсаалтад байгаа фонт, өнгө зурах явцад гарч ирвэл **зогсоод** гишүүнээс асуу. → [[04-Resources/Atomic/knowledge/2026-10-14 - Нэг брэнд, хоёр гадаргууд токен давхарга]]
5. **Бичвэрийн 3 түвшин ба scale** - бичвэр бүрийг дэгээ · агуулга · дэлгэрэнгүй гэж ангилж, суурь хэмжээ ба харьцааг brief-д бич (постер 1.333–1.5; дэгээ→агуулга ≥ 1.6). Жишээ: 1080 өргөнд дэгээ 96 · агуулга 48 · дэлгэрэнгүй 28 px. → [[04-Resources/Atomic/decisions/2026-10-14 - type-scale-three-levels]]
6. **Лавлагааны spec** - moodboard-оос «мэдрэмж» биш, сонгосон 1-2 лавлагааг тоогоор задал: багана, зах, gutter, type scale, фонтын хослол, өнгөний блок (hex, талбайн %), зургийн байрлал. Энэ spec-ийг brief-д хадгалж, зурахдаа түүнийг дага (Client B: v10-д 1:1 spec дагасны дараа л тогтворжсон).
7. **Фонт** - кирилл бүрэн фонт; **Ө ө Ү ү**-г тухайн фонтоор Figma-д бичиж харж шалга (fallback фонт орж ирвэл хэлбэр өөр харагдана). Брифийн «Хориг» фонттой (жишээ нь клиент гар бичмэлийг хориглосон) давхцаж буй эсэх. Нэг бүтээлд ≤ 2 бүл. → [[04-Resources/Atomic/knowledge/2026-10-14 - cyrillic-font-selection-check]]

## 1. Таван дүрэм (carousel ба пост бүрт)

1. **Шатлал** - гол 1-2 үгийг асар том, бусдыг жижиг. Нэг харцаар уншигдана. Слайд бүрд нэг санаа.
2. **Харааны хүч** - цагаан фон + энгийн фото биш: гүн өнгө, орон зай, контраст.
3. **Дэгээ = үр дүн** - сэдвийг биш, уншигчид юу болохыг хэл («X-ийг хаях», «7 хоногт Y»), «X-ийн тухай» биш.
4. **Хоёр өнгө** - нэг тод + нэг саармаг (+ фон). 3+ санамсаргүй өнгө = чимээ.
5. **Дараалал** - слайд бүр дараагийнхаа эрхийг олж авна; ижил толгой/хөл, слайдын дугаар.

## 2. 10 слайдын бүтэц (carousel)

| Слайд | Үүрэг |
|---|---|
| 1 | **Дэгээ** - үр дүн хэлбэрийн гарчиг, нэг том дүрс |
| 2-3 | **Жишээ** - асуудал эсвэл «өмнө / дараа» |
| 4-5 | **Үнэ цэнэ** - гол санаа, арга |
| 6-9 | **Үр шим / алхмууд** - нэг слайдад нэг алхам |
| 10 | **CTA** - хадгал, хуваалц, дагаарай, линк (нэг л үйлдэл) |

Богино carousel (5-7) бол 1 дэгээ · 1-2 жишээ · 2-3 үнэ цэнэ · 1 CTA. Текстийг эхлээд хүснэгтээр (слайд · **layout** · гарчиг · дэд текст · дүрс) гишүүнээр батлуулаад дараа нь зур.

**Layout жор (recipe)** - слайд бүрийг доорх нэрийн аль нэгээр төлөвлө (санамсаргүй өрөлт биш):

| Нэр | Бүтэц | Хэзээ |
|---|---|---|
| `hero-word` | 1-3 үг асар том, бусад нь жижиг нэг мөр | дэгээ, CTA |
| `split-50` | зүүн/баруун (эсвэл дээд/доод) тэнцүү: зураг + текст | өмнө/дараа, бүтээгдэхүүн |
| `big-number` | нэг тоо асар том + нэг тайлбар мөр | баримт, үр дүн |
| `list-3` | гарчиг + 3 мөр (дугаар/дүрстэй) | алхам, давуу тал |
| `quote` | ишлэл том, эх сурвалж жижиг | сэтгэгдэл, ишлэл |
| `full-bleed` | зураг бүтэн, текст safe zone дотор нэг блок | сэтгэл хөдлөл, бүтээгдэхүүн |
| `grid-4` | 2×2 карт, тус бүр дүрс + 2-3 үг | харьцуулалт, цэс |
| `map-pin` | газрын зураг/бүдүүвч + ≤ 5 шошго | байршил |

Нэг carousel-д 3-4 өөр жор хангалттай; ижил жорыг дараалан 3-аас олон удаа бүү ашигла.

## 3. Зурах

**Figma (`/fm:figma`)** - санал болгох:
1. Bridge асаалттай эсэх (`fig.py status`), зорих файл/хуудсыг `--doc`-оор.
2. Нэг frame = нэг слайд, нэр `NN · <гарчиг>` (жишээ `01 · Дэгээ`), auto layout, аюулгүй хүрээ ~88px. Frame үүсгэмэгц `scripts/safe_zones.js`-ээр safe zone guide нэм (feed 135 px дээд/доод, story 14% / 35% / 6%).
3. Өнгө, фонтыг Variables / Text styles-аар (брэндийн байвал түүнийг); 2 өнгөний дүрэм.
4. Монгол кирилл дэмждэг фонт (Inter, Manrope, Montserrat, Noto Sans...) - фонтоо ачаалаад зур.

**HTML / artifact** (Figma байхгүй үед): слайд бүр 1080×1350 `<section>`, CSS variables-аар 2 өнгө; `frontend-design` эсвэл `canvas-design` skill-ийг ашиглаж болно. PNG-г гишүүн browser-оос эсвэл headless screenshot-оор гаргана.

### Зураг generate хийх (AI)

Эх дүрэм: `03-Areas/Studio/v9 - зургийн систем` (композиц · линз · задрал · хэрэгслийн хольц). Зураг гаргах, moodboard үүсгэхийн өмнө **уншина**.

Хураангуй:
- **Нэг жороор олон зураг гаргахгүй.** Багц дотор хэрэгсэл заавал холино: гэрэл зураг · зурсан постер · 3D · хэвлэлийн хуудас · макро · баримтат · макет. Нэг хэв маяг давтвал «хэт нэгэн хэвийн» гэж буцна.
- **Композицийг тоогоор заа** — «доод гуравны нэгд», «нүүрнээс 5 дахин том». «Жижиг», «том» гэвэл биелдэггүй.
- **Линз сонголтыг prompt-д нэрлэ**: урт (85–200мм, тайван, шахсан) · энгийн (35–50мм, баримтат) · өргөн (16–24мм, бүсэлсэн) · макро. Өргөн линзийг fisheye болгож мурийлгахгүй.
- **Давталт/тор маягийн зураг** нэг багцад 5-аас хэтрэхгүй — хуримтлагдвал нүдэнд нэг юм шиг харагдана.
- **Анкор зураг эхэлж:** багц (олон зураг) гаргахаас өмнө нэг анкор зургийг (дэвсгэр, гэрэл, өнгөний температур, хүний дүр) гишүүнээр батлуул; бусад нь түүнтэй тааруулна. Prompt-ийг гурван блокоор бич: (1) **сэдэв ба үйлдэл** (хэн, юу, хаана — Улаанбаатар, бодит дэлгүүр), (2) **камер ба гэрэл** (линз, өнцөг, гэрэл), (3) **хориг** (FORBIDDEN жагсаалт, буруу дүр, хэт цэнхэр).
- Багц бэлэн болмогц анкор + шинэ зургуудыг Figma-д `_compare · <огноо>` frame-д хажуу хажууд тавьж (дэвсгэр, өнгөний температур, масштаб) харьцуул; зөрсөн зургийг дахин гарга.
- Зураг дотор **ямар ч бичиг гаргахгүй** — FORBIDDEN жагсаалтыг prompt бүрт бич (text, letters, words, numbers, logos, watermark).
- Хичээл/агуулгыг **зурган зүйрлэлээр** хэл, инфографикаар биш.

## 4. Шалгах (нийтлэхээс өмнө заавал)

- `scripts/contrast_check.js` - том текст (≥48px, bold ≥40) 3:1, бусад 4.5:1; зураг дээрх текстийг гараар.
- `scripts/check_layout.js` - TEXT давхцал, хүрээнээс халалт 0.
- `scripts/creative_check.js` - текст ≥ 18 px (хатуу), фонтын бүл ≤ 2, шатлал ≤ 3 түвшин ба зэргэлдээ харьцаа ≥ 1.25, текст safe zone дотор. 0 асуудалтай болтол зас (зориудаар зөрсөн бол шалтгааныг гишүүнд хэл).
- **360 px thumbnail:** `fig.py export <id> --scale 0.3333 --out x-360.png` → Read-ээр хар; дэгээ нэг харцаар уншигдаж байх ёстой. Зөвлөмж: хамгийн жижиг текст ≥ 28 px (18 нь доод хязгаар).
- HTML горимд: `node "${CLAUDE_PLUGIN_ROOT}/tools/browse/post_check.mjs" <slides.html> --shot <dir>` - жижиг текст, халалт, мөрийн хязгаар, фонт, шатлал, гарчгийн зай + слайд бүрийн 360 px зураг.
- Үсгийн алдаа, тоо, нэр, линк - эх сурвалжтай тулга.
- Export (`fig.py export <id> --format PNG --scale 1`) → Read-ээр харж гишүүнд үзүүл.

Нэг **үе** = нэрлэгдсэн нэг хүнээс ирсэн нэгтгэсэн нэг хариу (Messenger-ийн хэсэг хэсэг мессежийг нэг үе болгож нэгтгэ). **Засвар** (brief-д багтсан) үнэгүй; **өөрчлөлтийн хүсэлт** (brief-ээс гадуур) бол тусдаа ажил — гишүүнд тэмдэглэ. → [[04-Resources/Atomic/decisions/2026-10-14 - Санал хүсэлтийн үе ба өөрчлөлтийн хүсэлт]]

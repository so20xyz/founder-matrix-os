# fm:post - пост, carousel, poster

Vault: `${user_config.vault_path}` (доор `<V>`). Зурах хэрэгсэл: `/fm:figma` (Figma bridge) - байхгүй бол HTML/artifact. Moodboard: Creative агент (Pinterest → Soulcatcher).

## 0. Brief (нэг удаад нэг асуулт)

1. **Хэнд, юуны төлөө** - төсөл/брэнд (`<V>/03-Projects/...`), уншигч, зорилго (дагагч, борлуулалт, сургалт).
2. **Формат:** carousel (1080×1350, 4:5, ≤10 слайд) · post (1080×1350) · story/reel cover (1080×1920) · poster (A3/A2 эсвэл px).
3. **Брэнд:** төслийн note-д `brand`, өнгө, фонт, лого байгаа эсэхийг шалга (`<V>/03-Projects/<төсөл>/`, `05-Resources/`). Moodboard байвал (`MB · ...` reference) түүнийг уншина. Байхгүй бол «moodboard хийх үү?» → Creative агент.
4. Эх агуулга: атом, лавлагаа, яриа - **баримтыг зохиохгүй**; тоо, ишлэл бүр эх сурвалжтай.

## 1. Таван дүрэм (carousel ба пост бүрт)

1. **Шатлал** - гол 1-2 үгийг асар том, бусдыг жижиг. Нэг харцаар уншигдана. Слайд бүрд нэг санаа.
2. **Харааны хүч** - цагаан фон + энгийн фото биш: гүн өнгө, орон зай, контраст.
3. **Дэгээ = үр дүн** - сэдвийг биш, уншигчид юу болохыг хэл («X-ийг хаях», «7 хоногт Y»), «X-ийн тухай» биш.
4. **Хоёр өнгө** - нэг тод + нэг саармаг (+ фон). 3+ санамсаргүй өнгө = чимээ.
5. **Дараалал** - слайд бүр дараагийнхаа эрхийг олж авна; ижил толгой/хөл, слайдын дугаар.

## 2. 10 слайдын бүтэц (carousel)

| Слайд | Үүрэг |
|---|---|
| 1 | **Дэгээ** - үр дүн хэлбэрийн гарчиг, нэг том дүрс |
| 2-3 | **Жишээ** - асуудал эсвэл «өмнө / дараа» |
| 4-5 | **Үнэ цэнэ** - гол санаа, арга |
| 6-9 | **Үр шим / алхмууд** - нэг слайдад нэг алхам |
| 10 | **CTA** - хадгал, хуваалц, дагаарай, линк (нэг л үйлдэл) |

Богино carousel (5-7) бол 1 дэгээ · 1-2 жишээ · 2-3 үнэ цэнэ · 1 CTA. Текстийг эхлээд хүснэгтээр (слайд · гарчиг · дэд текст · дүрс) гишүүнээр батлуулаад дараа нь зур.

## 3. Зурах

**Figma (`/fm:figma`)** - санал болгох:
1. Bridge асаалттай эсэх (`fig.py status`), зорих файл/хуудсыг `--doc`-оор.
2. Нэг frame = нэг слайд, нэр `NN · <гарчиг>` (жишээ `01 · Дэгээ`), auto layout, аюулгүй хүрээ ~88px.
3. Өнгө, фонтыг Variables / Text styles-аар (брэндийн байвал түүнийг); 2 өнгөний дүрэм.
4. Монгол кирилл дэмждэг фонт (Inter, Manrope, Montserrat, Noto Sans...) - фонтоо ачаалаад зур.

**HTML / artifact** (Figma байхгүй үед): слайд бүр 1080×1350 `<section>`, CSS variables-аар 2 өнгө; `frontend-design` эсвэл `canvas-design` skill-ийг ашиглаж болно. PNG-г гишүүн browser-оос эсвэл headless screenshot-оор гаргана.

### Зураг generate хийх (AI)

Эх дүрэм: `08-Studio/v9 - зургийн систем` (композиц · линз · задрал · хэрэгслийн хольц). Зураг гаргах, moodboard үүсгэхийн өмнө **уншина**.

Хураангуй:
- **Нэг жороор олон зураг гаргахгүй.** Багц дотор хэрэгсэл заавал холино: гэрэл зураг · зурсан постер · 3D · хэвлэлийн хуудас · макро · баримтат · макет. Нэг хэв маяг давтвал «хэт нэгэн хэвийн» гэж буцна.
- **Композицийг тоогоор заа** — «доод гуравны нэгд», «нүүрнээс 5 дахин том». «Жижиг», «том» гэвэл биелдэггүй.
- **Линз сонголтыг prompt-д нэрлэ**: урт (85–200мм, тайван, шахсан) · энгийн (35–50мм, баримтат) · өргөн (16–24мм, бүсэлсэн) · макро. Өргөн линзийг fisheye болгож мурийлгахгүй.
- **Давталт/тор маягийн зураг** нэг багцад 5-аас хэтрэхгүй — хуримтлагдвал нүдэнд нэг юм шиг харагдана.
- Зураг дотор **ямар ч бичиг гаргахгүй** — FORBIDDEN жагсаалтыг prompt бүрт бич (text, letters, words, numbers, logos, watermark).
- Хичээл/агуулгыг **зурган зүйрлэлээр** хэл, инфографикаар биш.

## 4. Шалгах (нийтлэхээс өмнө заавал)

- `scripts/contrast_check.js` - том текст (≥48px, bold ≥40) 3:1, бусад 4.5:1; зураг дээрх текстийг гараар.
- `scripts/check_layout.js` - TEXT давхцал, хүрээнээс халалт 0.
- Утасны дэлгэц дээр унших: 1080px → ~360pt. Хамгийн жижиг текст ≥ 28px.
- Үсгийн алдаа, тоо, нэр, линк - эх сурвалжтай тулга.
- Export (`fig.py export <id> --format PNG --scale 1`) → Read-ээр харж гишүүнд үзүүл.

## 5. Хадгалах

- Зураг: `<V>/03-Projects/<төсөл>/Output/<YYYY-MM-DD> <гарчиг>/NN.png` (эсвэл төслийн өөрийн бүтэц). Caption, hashtag → тэр хавтасны `caption.md` (frontmatter `type: reference`, `kind: doc`, `projects: [төсөл]`, `ai-first: true`).
- Төслийн note-д `## Нийтлэл` хэсэгт мөр: `- YYYY-MM-DD [[.../caption]] - <гарчиг> (Figma: <линк>)`.
- Шинэ дүрэм, сургамж гарвал `/fm:save` (атом).

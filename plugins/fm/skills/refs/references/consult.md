# Зөвлөгөөн: memo ба дарга (task 4)

Харилцаа файлаар. Нэг файл = нэг бичигч. Figma коммент нь зөвхөн тэмдэглэл, шийдвэр файлд.

## Memo (дүр бүр, Sonnet)

Дүр бүрт өөрийн дүрийн note-ийг (`03-Areas/AI Team/ai-workers/<Дүр>.md`) ачаалуулж, ингэж өг. Сешн байхгүй эсвэл нээж чадахгүй бол `fm:creative` / `fm:architect` subagent (Sonnet), нэг удаагийн хариуг `SendMessage`-ээр тэр agent руу:

```
Чи <дүр>. Тайлан: [[<тайлан>]], Figma node <node>. Өөрийн өнцгөөс memo бич:
02-Projects/<P>/research/consult-<slug>.md

- Creative: визуал хэл, UX, брэндтэй нийцэл.
- Architect: төслийн одоогийн стек дээр хэрэгжүүлэх өртөг (S/M/L), эрсдэл, хамаарал; `_existing.md`-тэй тулгаж «аль хэдийн бий» гэж тэмдэглэ.
- (Өөр дүр: spec-д заасан өнцөг.)

Карт бүрт (R<n>): 👍/👎 + 1 өгүүлбэр шалтгаан. Төгсгөлд өөрийн топ 5–7.
Дараа нь бусдын memo-г уншаад, өөрийн файлын «## Хариу» хэсэгт НЭГ удаа хариул (санал нийлэх/зөрөх, яагаад).
Бусдын файлд бүү бич. Тайлан ≤8 мөр.
```

Дараалал: бүх memo бичигдэнэ → бүгд нэг удаа хариулна → дарга. Хоёр дахь тойрог байхгүй.

## Дарга (Opus, шинэ context)

```
Чи зөвлөгөөний дарга. Spec [[<spec>]], тайлан [[<тайлан>]], memo-ууд: <жагсаалт>.
02-Projects/<P>/research/consult-decision.md-д бич:

## ⭐ Онцлох (5–7)
| R<n> | Нэр | Яагаад | Өртөг (S/M/L) |

## Ruling
Маргаан бүрт: асуудал → шийдвэр → шалтгаан → «буруу байвал юу алдах вэ».

## Soyol-д тавих асуулт
2–4 сонголт (fig.py ask нь ≤4): 5–7 ⭐-ийг ≤4 багц болго, жишээ «B · Шүүлт: chip + холбоос хуулах (R3 + R5) - S + S». Тус бүр 1 мөр, Figma node.

## Soyol-ийн сонголт
(хоосон — зохицуулагч бөглөнө)
```

Ruling-ийг Soyol-д ил харуулна (pipeline ✅ 9).

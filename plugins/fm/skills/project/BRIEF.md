# Fork / side session / subagent-ийн brief загвар (Project agent)

itge.e 2026-11-12: төслийн Project чат = ганц цонх. Fork, side session, subagent-ийн асуулт, батламж, тайлан **эх Project сешнээр** дамжина; itge.e fork бүрт орж хариулахгүй. Дүрэм: vault-ийн `03-Areas/AI Team/ai-workers/Project.md` → «🧭 Дүрэм (2026-11-12)».

## Эх сешний хаяг — зөв id

| Юу | Хэлбэр | Хаана харагдана | SendMessage-д |
|---|---|---|---|
| Desktop-ийн session id | `local_<uuid>` | `start_session`-ийн хариу, «Linked sessions now» тэмдэглэл, `list_sessions {"linked": true}`, `ListAgents`, дэд сешний system prompt («SendMessage (`to`: `local_…`)») | ✅ энийг |
| Claude Code-ийн sid | `<uuid>` (угтваргүй) | SessionStart hook, relay `--sid`, registry.json | ❌ хэзээ ч |

2026-11-12-нд хоёр сешн `local_47a10d33…` гэж sid-ийг `local_` угтвартай болгоод илгээх гэж оролдож бүтэлгүйтэв. **Id-г таамаглаж, хувиргаж бүү бич** — зөвхөн дээрх эх сурвалжаас хуулна. Дэд сешн эргэлзвэл `ListAgents`-аас «📁 <Төсөл>» нэртэйг олно.

Эх сешн өөрийн `local_…` id-гоо мэдэхгүй бол brief-д бичихгүй: `start_session`-ээр нээсэн дэд сешний system prompt-д эх сешний id автоматаар ордог. Тэр үед brief-д «эх сешн = `ListAgents`-ийн «📁 <Төсөл>» (<төхөөрөмж>)» гэж нэрээр нь заа.

## Загвар (brief-ийн төгсгөлд хуулж нэм)

```
Харилцах дүрэм (заавал):
- itge.e-ээс шууд бүү асуу. Асуулт, батламж (push, merge, устгах, нийтлэх), блок — бүгдийг
  SendMessage-ээр эх Project сешн рүү: to = <local_… эсвэл «ListAgents-ийн 📁 <Төсөл> (<PC|Mac>)»>.
  Нэг мессежинд нэг асуулт; хоёр ба түүнээс олон шийдвэр бол сонголтуудыг жагсаа (санал болгохыг эхэнд) —
  эх сешн тэдгээрийг картаар itge.e-д тавина.
- Явцын мэдээ бүү илгээ (дууссаны тайлан автоматаар очно).
- Дуусахдаа ≤10 мөр тайлан: юу өөрчилсөн (файл, commit/PR) · юугаар шалгасан · юу үлдсэн.
- Vault-ийн task-ийн checkbox-ыг шинэчил, `_system/logs/<YYYY-MM-DD>.md`-д
  `- **HH:MM** · <дүр> → <нэг мөр> · [[01-GTD/Tasks/<task>]]` мөр нэм.
```

## Эх Project сешний үүрэг

1. Дэд сешнээс ирсэн асуултыг itge.e-д **өөрийн чатаар** тавина (2+ шийдвэр → `AskUserQuestion` / сонголтот карт).
2. itge.e-ийн хариуг үгчлэн иш татаж (`«…»`) дэд сешн рүү SendMessage-ээр буцаана.
3. Тайлан ирэхэд үр дүнг (diff, файл) шалгаад л «болсон» гэнэ; `sync` тайланд хүлээгдэж буй сешнүүдийг жагсаана.

# /fm:log - task-ийн өөрчлөлтийн түүх

Нэг ажлын урсгал = нэг task (BOOT, itge.e 2026-10-10). Энэ команд тэр task-ийн түүхэнд мөр нэмнэ; Цаглабар (fm 0.9.4+) task-ийн доор `HH:MM юу` гэж харуулна. Файл засвар бүрийг `fm_changelog.py` hook аль хэдийн нэмдэг — `/fm:log` нь «юу, яагаад»-ыг хүнд ойлгомжтой нэг мөрөөр нэмэх, эсвэл нөхөж бичих.

## Алхам

1. **Task-аа ол** (эхнийх нь таарвал зогс):
   - `~/.fmos/active-task/<sid>` файл (сешний `relay.py claim` хожсон task-ийн vault-relative зам).
   - `01-GTD/Tasks/` дотор `status: in-progress`, `claimed: <энэ төхөөрөмж>` бөгөөд энэ ярианы сэдэвтэй таарах task.
   - Олдохгүй бол: «Аль task-д бичих вэ?» гэж нэг асуултаар тодруул (эсвэл `relay.py task` → `claim`-аар шинэ task — зөвхөн хэрэглэгч зөвшөөрвөл).
2. **Цаг**: `date +%H:%M` (хэзээ ч бүү таа). Хуучин үйлдлийг нөхөж бичвэл ярианд гарсан бодит цагийг ашигла.
3. **Мөр**: `| HH:MM | <юу хийсэн, монголоор, нэг өгүүлбэр> | <хаана: файл/зам/тохиргоо, нөөцийн нэр> |`. `|` тэмдэгтийг `/` болго.
4. **Бичих** (Read → Edit, байгаа мөрийг бүү өөрчил):
   - «## Өөрчлөлтийн түүх» байвал хүснэгтийн сүүлийн мөрийн дараа нэм.
   - Байхгүй бол task-ийн төгсгөлд `## Өөрчлөлтийн түүх` + `| Цаг | Юу | Хаана |` + `|---|---|---|` толгойтой үүсгэ.
   - Өмнөх мөртэй ижил (юу + хаана) бол бүү давхарла.
5. **Google Calendar шинэчлэх** (vault → calendar, нэг талын; Google Calendar connector байвал):
   - Calendar-ууд: `🤝 Task · itge.e × Claude` (agent-тай хамт хийсэн/хийх task) · `✅ Task · itge.e` (гишүүн өөрөө) · `📅 Уулзалт` · `🔁 Routine`. Хувийн (🔒, finances/) task-ийг хувийн calendar-т зөвхөн ерөнхий нэрээр, эсвэл огт бүү гарга.
   - Task-ийн event-ийг гарчгаар хай (`<угтвар> [Төсөл] <юу> · <дүрс> <дүр>`, жишээ `🤝 [Season 2] Premiere-ийг товчоор удирдах · 🏛 Architect`). Байхгүй бол үүсгэ: эхлэх = `started:`, дуусах = `completed:` (эсвэл одоо); хугацаатай (`due:`) task бол тэр өдөр бүтэн өдрөөр. Agent-тай task `availability: free`.
   - Тайлбарыг (HTML) task-аас дахин бүтээ: гарчиг · төлөв, «Үр дүн», «Өөрчлөлтийн түүх»-ийн сүүлийн ~12 мөр (shell командын мөрийг алгас), `Vault: <task зам>`, төгсгөлд `— vault → calendar шинэчлэл (/fm:log)`. Calendar дээрх гар засварыг дарна — засварыг vault-д хий.
   - `notificationLevel: NONE`; давхар event бүү үүсгэ.
6. **Тайлан**: нэг мөр — `🪵 [[task]] ← HH:MM юу` (+ `📅 calendar шинэчлэгдсэн`).

## Хориг
- 🔒 хувийн task-д (private, finances/) бичихгүй.
- Хаагдсан (`completed`) task-д бичих бол эхлээд хэрэглэгчээс асуу, эсвэл «## Үр дүн»-д нэмэлт мөр болгон бич.
- Агуулгыг `_system/logs`-д бүү давхарла (лог = зөвхөн холбоос).

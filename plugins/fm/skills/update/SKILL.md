# fm:update - ганц команд

**Хэрэглэгч зөвхөн `update` гэж бичнэ.** Бусад fm skill (`save`, `inbox`, `task`, `people`, `project`, `finance`) бол энэ командын **барилгын блок**: update тэдгээрийн журмыг (тухайн skill-ийн SKILL.md-г Read-ээр уншаад) дотроосоо гүйцэтгэнэ. Хэрэглэгчээс «одоо `/fm:save` ажиллуул» гэж хэзээ ч бүү гуй — өөрөө хий.

Vault: `${user_config.vault_path}` (доор `<V>`). Төхөөрөмж: `${user_config.device}`. Дүрэм: `<V>/_system/BOOT.md`.

## 0. Горим ба бэлтгэл

| `$ARGUMENTS` | Горим | Юу хийнэ |
|---|---|---|
| хоосон, текст, «sync», «шинэчил» | **оркестр** (анхдагч) | доорх 1-9 алхам |
| «хурдан» | оркестр-хурдан | 1, 2 (зөвхөн task), 8, 9 — inbox, хүн, төсөл алгасна |
| «daily», «өглөө», «өдрийн тэмдэглэл» | `daily` | (D) өдрийн note: фокус, хугацаа болсон task, өчигдрөөс |
| «дүгнэлт», «орой», «өдрөө хаая», «өдрийн дүгнэлт» | оркестр + (E) | 1-9 алхам + өдрийн дүгнэлт атом |
| «weekly», «долоо хоног», «тойм» | `weekly` | (W) долоо хоногийн тойм (+ оркестр-хурдан) |

1. Огноо, цаг, гарагийг системээс ав: `date +%F`, `date +%H:%M`, `date +%u` (1 = Даваа). **Хэзээ ч бүү таа.**
2. **Дүр.** Сешний context-ийн `Дүр: <slug>` мөр. Байхгүй бол: «Дүр тогтоогоогүй байна. `/fm:role <slug>` ажиллуулах уу, эсвэл `${user_config.member}` нэрээр шинэчлэх үү?» - хариу ирэхээс өмнө STATUS-д бүү бич.
3. **Хувийн горим.** Context-д `PRIVATE сешн` эсвэл дүрийн note-д `private: true` (Finance) бол доорх 🔒 хэсэг хүчинтэй.
4. **Хамрах хүрээ:** өнөөдрийн логоос энэ дүрийн сүүлийн `update`/`save` мөрийг ол — **түүнээс хойшхи** ярианы хэсгийг л боловсруул (давхардал үүсгэхгүй).
5. Албан ёсны `productivity` plugin-ий update-ийг **бүү** ажиллуул - тэр `TASKS.md`, `memory/` бичиж хоёр дахь санах ой үүсгэдэг. Энэ skill бүгдийг vault-д хийнэ.

## Оркестр — дараалал ба хэзээ алгасах

Алхам бүрийг **дотооддоо** шийд: хийх зүйл байхгүй бол чимээгүй алгас (хэрэглэгчээс «X хийх үү?» гэж асуухгүй). Хэрэглэгчээс зөвхөн дараах үед асууна: inbox-оос зөөх, шинэ хүний note үүсгэх, төслийн төлөв солих, task дууссан гэж тэмдэглэх, 🔒 санхүүгийн бичилт.

| # | Алхам | Блок (журам) | Хэзээ алгасах |
|---|---|---|---|
| 1 | **Барьж авах** — шинэ шийдвэр, ойлголт, нээлттэй асуултыг атом болгох (+ PARA холбоос) | `fm:save` (`--checkpoint` түвшин; URL байвал URL горим) | Сүүлийн update/save-ээс хойш шинэ баримт, шийдвэр гараагүй |
| 2 | **Task** — ярианд гарсан «дараагийн алхам»-ыг эзэнтэй task болгох; хийгдсэнийг `completed` (асууна), өөрчлөгдсөний `status`/`due` | `fm:task` | Шинэ/өөрчлөгдсөн task алга |
| 3 | **Хүмүүс** — дурдагдсан хүн бүрийн note-д харилцааны мөр, `last_interaction`; шинэ хүн бол «note үүсгэх үү?» | `fm:people` (touch / new) | Ярианд хүн дурдагдаагүй эсвэл зөвхөн дамжуулж дурдсан |
| 4 | **Төсөл** — төслийн note-д огноотой ахицын мөр, `## Гол шийдвэр`-т атомын холбоос; `_BRAIN` зөвхөн «яагаад / дууссан гэж юу» өөрчлөгдвөл; төлөв солих бол асуу | `fm:project` | Ажил ямар ч төсөлд хамаарахгүй |
| 5 | **Inbox** — `00-Inbox/`-д зүйл байвал ангилж төлөвлөгөөний хүснэгт гарга → **батлуулаад** л зөө | `fm:inbox` | Inbox хоосон; оркестр-хурдан; эсвэл энэ өдөр аль хэдийн цэгцэлсэн бол зөвхөн тоог хэл |
| 6 | **Өдрийн note** — өнөөдрийн note байхгүй бол үүсгэ (D), `## 💼 Ажил`-д энэ удаагийн атом/task холбоос | (D) доор | Note-д холбоос аль хэдийн байгаа |
| 7 | **🔒 Санхүү** — зөвхөн `PRIVATE сешн` (Finance): төлбөрийн сануулга, шинэ төлбөр/гүйлгээг бүртгэх (асууна) | `fm:finance` | Finance биш бол **үргэлж** алгас (хувийн хавтсанд орохгүй) |
| 8 | **STATUS + лог** — энэ дүрийн мөр, нэг холбоостой лог мөр | (A) доор | Хэзээ ч алгасахгүй (🔒 Finance бол `_state.md`) |
| 9 | **Миний task-ууд + бусдын мэдээ** | (B) доор | Хэзээ ч алгасахгүй |

**Эцсийн тайлан** (нэг блок, ≤10 мөр):
```
✅ update · <дүр> · HH:MM
⚛️ Атом N · ✅ Task +N / ✔ N · 👤 Хүн N · 🔨 Төсөл N · 📥 Inbox: N зөөсөн / M хүлээж байна
🧭 STATUS: «<хийсэн → зогссон → дараагийн алхам>»
📋 Нээлттэй task: N (⚠️ хэтэрсэн M) - эхний 3
👀 Бусдаас: <≤3 мөр эсвэл юу ч биш>
❓ Асуух: <батлуулах зүйлс - inbox, шинэ хүн, төлөв>
```

## (A) Алхам 8 - STATUS мөр ба лог

1. Ярианаас (эсвэл `$ARGUMENTS`-аас) гарга: **Хийсэн** (1-3 зүйл) · **Зогссон** (юун дээр, хэнээс юу хүлээж байна) · **Дараагийн алхам**. 1-5-р алхамд үүссэн атом, task-ийн холбоосыг цуглуул.
2. `<V>/_system/STATUS.md` - бүх дүрийн нэг самбар, **дүр бүр нэг мөр**:
   ```markdown
   | Дүр | Сүүлд (огноо · төхөөрөмж) | Хаана зогссон → дараагийн алхам |
   |---|---|---|
   | [[02 Area]] | YYYY-MM-DD HH:MM · <төхөөрөмж> | <хийсэн> → <зогссон> → <дараагийн алхам> · [[атом]] |
   ```
   - Read-ээр унш. Эхний баганаас өөрийн дүрийн note-ийн холбоосыг ол (context-ийн `Дүр: <slug> ([[...]])`). Олдвол зөвхөн тэр мөрийн 2, 3-р нүдийг Edit-ээр соль; олдохгүй бол хүснэгтийн төгсгөлд мөр нэм. Frontmatter `updated:`-ийг шинэчил.
   - Файл байхгүй бол үүсгэ: frontmatter `type: system`, `updated:`, `ai-first: true`; `# 🧭 STATUS - дүр бүр хаана зогссон`; хүснэгтийн толгой ба өөрийн мөр.
   - Нүд: нэг мөрөнд, `|` тэмдэгтгүй (wikilink-ийн `|alias` ч хориотой), ≤250 тэмдэгт, агуулга биш **холбоос**.
   - Бусад дүрийн мөрөнд хэзээ ч бүү хүр. Файлыг Write-аар дарж бичихгүй.
3. Лог (`_system/logs/<огноо>.md`, Read → Edit, төгсгөлд): `- **HH:MM** · <дүр> → update · [[_system/STATUS]] · [[атом]] · [[task]]`
4. Discord relay тохируулсан бол (`/fm:relay`) Stop hook baton-ийг өөрөө бичнэ - энд юу ч бүү илгээ.

## (B) Алхам 9 - миний task-ууд, бусдын мэдээ

1. **Бусдын мэдээ.** `STATUS.md`-ийн бусад мөр, өнөөдрийн логийг унш. **Энэ дүрд хамаатай** зүйл (өөр дүр надаас юм хүлээж байна, давхардсан ажил, миний хүрээний шийдвэр) байвал ≤3 мөрөөр хэл. Үгүй бол юу ч бүү хэл.
2. **Нээлттэй task.** `<V>/02-GTD/tasks/`-д Grep (`output_mode: files_with_matches`): `^owner:\s*["']?(<slug>|@?<дүрийн нэр>)["']?\s*$`. Дүргүй сешнд `owner: me` болон `owner: "@${user_config.member}"`. Frontmatter-аас `status`, `priority`, `due`, `project`-ийг унш; `completed`, `cancelled` (хуучин `done`)-ийг хас. Эрэмбэ: хугацаа хэтэрсэн (⚠️) → priority (`high` → `medium` → `low`; хуучин 🔴 → 🟡 → 🟢) → `due`.
   | Task | Төлөв | Чухал | Хугацаа | Төсөл |
   |---|---|---|---|---|
3. Энэ сешнд дууссан task байвал зөвшөөрөл аваад `status: completed`, `updated:`, `## Хүргэсэн` хэсэгт нэг мөр.

## (D) daily - өдрийн тэмдэглэл

**Гол зарчим:** хэрэглэгчийн бичсэн юу ч **хэзээ ч дарж бичигдэхгүй**. Агент зөвхөн өөрийн хэсгүүдийг нэмж, шинэчилнэ. Огноо: `$ARGUMENTS`-д `YYYY-MM-DD` байвал тэр, үгүй бол өнөөдөр. Гараг: 1 Даваа · 2 Мягмар · 3 Лхагва · 4 Пүрэв · 5 Баасан · 6 Бямба · 7 Ням.

1. **Үүсгэх / нээх** `<V>/02-GTD/daily/YYYY-MM-DD.md`.
   - Байхгүй бол `<V>/_system/templates/Daily Note.md`-г уншиж тэмдэгтүүдийг гараар соль (Obsidian ажиллаагүй тул plugin орлуулахгүй): `{{date:YYYY-MM-DD}}`, `{{date}}`, `<% tp.date.now("YYYY-MM-DD") %>` → огноо; `{{date:dddd}}` → монгол гараг; `{{title}}`, `<% tp.file.title %>` → `YYYY-MM-DD`; `{{time}}` → `HH:MM`; бусад `<% ... %>` → хоосон. Загвар байхгүй бол хамгийн бага бүтэц: frontmatter (`date`, `type: daily`, `tags: [daily]`, `ai-first: true`, `focus: []`), `# YYYY-MM-DD - <гараг>`, `## For future agent`, `## 🎯 Өнөөдрийн гол 3`, `## 💼 Ажил`, `## 🌙 Оройн дүгнэлт`.
   - Байгаа бол Read-ээр уншаад бүх өөрчлөлтийг **Edit-ээр, хэсэг хэсгээр**.
2. **Хөндөхгүй:** frontmatter-ийн `focus:`, `mood:`, `energy:`, `habit_*:`; `**Өдрийн зорилго:**`, `**Талархал:**`, `## 🏠 Хувийн`, `## 📥 Inbox`, оройн дүгнэлтийн хэрэглэгчийн мөрүүд, `> 💬 ...` сэтгэгдэл. Тэнд өнөөдрийн хүсэлт/асуулт бичсэн бол **шинэ оролт** гэж уншаад хариулах эсвэл task болгох эсэхийг асуу.
3. **Фокус** `## 🎯 Өнөөдрийн гол 3` (хуучин `## 🎯 Today's Focus`):
   - Хэрэглэгчийн `focus:` эхэнд (🔴 #1, 🟡 #2, 🟢 #3). Task хэзээ ч хэрэглэгчийн фокусыг шахахгүй.
   - `### 📌 Хугацаа болсон` - `02-GTD/tasks/`-аас `due` ≤ өнөөдөр, нээлттэй, `owner` нь `me` / `"@${user_config.member}"` / энэ дүр: `- [[02-GTD/tasks/<нэр>]] - due YYYY-MM-DD` (хэтэрсэн бол ⚠️).
   - `### ↪️ Өчигдрөөс` - өчигдрийн `**Маргаашийн #1:**` (хуучин `**Tomorrow's #1 priority:**`) болон STATUS дахь энэ дүрийн «дараагийн алхам».
   - Агентын дэд хэсгүүдийг (`📌`, `↪️`) дахин ажиллуулахад **бүхэлд нь сольж** шинэчил.
4. **Ажил** `## 💼 Ажил` (хуучин `## 💼 Work Log`): энэ яриа болон өнөөдрийн логийн атом, task, лавлагааны холбоос, мөр бүр `- [[...]] - нэг мөр`. Байгаа холбоосыг давтахгүй. Хуанли холбогдоогүй бол хуанлийн хэсгийг бүү зохио.
5. **🔒 Төлбөрийн сануулга** - зөвхөн `PRIVATE сешн` (Finance). `private/` доторх `type: bill`, `status: active`, `due_day` ≤ өнөөдрийн өдөр, `last_paid` энэ сард биш bill байвал: `- 🔒 Төлбөр: N зүйл хугацаа болсон → [[04-Areas/Business/finances/private/Сарын төлбөр]]`. Дүн, нэр, данс бичихгүй. Бусад дүр энэ алхмыг чимээгүй алгасна.
6. Шинээр үүсгэсэн бол лог: `- **HH:MM** · <дүр> → daily: [[02-GTD/daily/YYYY-MM-DD]]` (шинэчлэл бүрд биш). Хэрэглэгчид: note-ийн зам + 3 мөр (фокус N · хугацаа болсон N (⚠️ M) · өчигдрөөс 1 мөр).

## (E) daily дүгнэлт - өдрийн дүгнэлт атом (зөвхөн хүсэлтээр)

1. Эх сурвалж: өнөөдрийн лог, өнөөдөр үүссэн атомууд (`06-Atomic/**/<огноо> - *`), STATUS-ийн өөрийн мөр, энэ ярианы гол утга.
2. Өдрийн хамгийн чухал **1 утсыг** сонго (ойлголт, шийдвэр эсвэл ахиц).
3. Атом `06-Atomic/knowledge/YYYY-MM-DD - odriin-dugnelt-<slug>.md`: `type: atomic`, `kind: daily-conclusion`, `tags: [atomic, daily-conclusion]`, `confidence: stated` (хэрэглэгчийн үг) эсвэл `medium`, `sources: ["[[_system/logs/YYYY-MM-DD]]", "[[02-GTD/daily/YYYY-MM-DD]]"]`, `role`, `areas: ["[[04-Areas/AI Team/ai-workers/<дүрийн note>]]"]`, `ai-first: true`. Бие: `# <гол утга - нэг өгүүлбэр>` → `## For future agent` → `## Дүгнэлт` (2-4 өгүүлбэр, **хэрэглэгчийн өөрийн үгээр**) → `## Өдрийн тоо` (N атом, N task дууссан, N шинэ - бодит эх сурвалжаас) → `**Холбоос:**`. Өнөөдөр аль хэдийн байвал баяжуул.
4. Өдрийн note-ийн `## 🌙 Оройн дүгнэлт`-д (хуучин `## 🌙 Evening Review`) `[[атом]]` холбоос. Лог: `- **HH:MM** · <дүр> → дүгнэлт: [[...]]`. Хэрэглэгчид харуулаад «засах уу?».

## (W) weekly - долоо хоногийн тойм

Зорилго: долоо хоногт нэг удаа системийг «цэвэр» байдалд оруулах. **Эхлээд тайлан, дараа нь зөвшөөрөлтэй засвар** - юуг ч асуулгүй бүү өөрчил.

1. **Хүрээ:** сүүлийн 7 хоногийн лог (`_system/logs/`), өдрийн note-ууд, шинэ атомууд.
2. **Task-ууд** (`02-GTD/tasks/`, нээлттэй): хугацаа хэтэрсэн; `updated` 14+ хоног хөдлөөгүй `next-action`/`waiting`; эзэнгүй (`owner` хоосон) эсвэл `project: TBD`. Тус бүрд санал: дуусгах · хойшлуулах (`due`) · `someday` · цуцлах · эзэн оноох.
3. **Төслүүд** (`03-Projects/1-Active/`): энэ 7 хоногт ямар ч task, атом, `_BRAIN` хөдөлгөөнгүй төсөл → «On-hold болгох уу?» (`/fm:project`).
4. **Хүмүүс:** `04-Areas/people/`-ийн hot list (`hot: true`) дотор `last_interaction` 30+ хоног болсон хүн → «холбогдох уу?» (`/fm:people`).
5. **Inbox:** `00-Inbox/` дахь зүйлийн тоо; 7+ хоносон зүйл байвал `/fm:inbox` санал болго.
6а. **🧠 Тархины шалгалт:** `python3 "${CLAUDE_PLUGIN_ROOT}/skills/vault/scripts/fm_brain_check.py" <V> --mark-bridges` → харьяалалгүй, ашиглагдаагүй resource, эхгүй атом, «яагаад»-гүй холбоосын тоо + жишээ 3; гүүр атомуудыг тайланд нэрлэ. Засварыг зөвшөөрлөөр.

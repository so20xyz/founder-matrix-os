Obsidian Local REST API plugin ашиглавал хадгалахад Obsidian урд гарахгүй (фокус солихгүй), урт нийтлэл ч бүрэн орно.

Obsidian тохиргоо -> Community plugins -> Local REST API -> "API Key" хэсгээс хуулна.
HTTP (шифрлэлтгүй) сервер. Plugin тохиргоонд "Enable Non-encrypted (HTTP) Server" асаа, порт 27123.
API key-гүй үед obsidian://-ээр хадгална. Ижил нэртэй хоёр vault байвал Obsidian-ий vault ID-г бич (Obsidian → Manage vaults).

Тохируулах алхам

  1. Obsidian -> Settings -> Community plugins -> Browse -> Local REST API суулга, идэвхжүүл
  2. Local REST API тохиргоонд Enable Non-encrypted (HTTP) Server-ыг ASAA (порт 27123)
  3. Мөн тэндээс API Key-г хуулж дээрх талбарт тавь -> Хадгалах
  4. Болоо. Одоо popup-ын "хадгалах" нь Obsidian урд гаргахгүй шууд бичнэ.

API key тохируулаагүй бол extension нь хуучин `obsidian://` аргаар (Obsidian урд гарна) ажилласаар байна - regression байхгүй.
